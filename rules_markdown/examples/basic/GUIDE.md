## Introduction

`rules_markdown` composes independent markdown fragments into one document —
ordered by weight, with a generated table of contents and resolved
cross-fragment deep links. Each fragment is a Bazel target, so docs assemble
from the build graph the same way code does.

## Usage

Declare a `markdown_fragment` per section, then aggregate them with
`markdown_document`. See [the introduction](#introduction) for the idea — that
link is a deep link resolved at build time to the Introduction section's
anchor, and the build fails if it ever dangles.
