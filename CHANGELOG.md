# Changelog

## v0.0.2

- **Namespace the default base image's repo** (`distroless_static` →
  `rules_k8s_distroless_static`). A module extension's repos are shared across the
  whole module graph, so pulling a base named `distroless_static` collided with
  any consumer that pulled its own — which is most operator repos:

      A repo named distroless_static_linux_amd64 is already generated by this
      module extension

  **v0.0.1 is yanked**: it is unusable in exactly the repos this module is for.
  Found by the first real consumer, minutes after publishing.

## v0.0.1 (unreleased)

First cut: `k8s_crd_library` — controller-tools as a real Bazel action.

- **`k8s_crd_library`** turns kubebuilder markers into CRD YAML as a declared
  TreeArtifact, in a sandboxed and cached action. No host Go, no `go list`, no
  module cache, no network, no `bazel query`. Verified byte-identical to stock
  `controller-gen v0.16.5` (`//examples/smoke:crds_match_stock_controller_gen`).
- **`//crd/private/driver`** — a `go/packages` external driver that answers from
  the `pkg.json` files rules_go's `go_pkg_info_aspect` already emits. This is the
  piece that makes the above possible; rules_go's own driver can't be used
  because it shells out to `bazel query`.
- **`K8sCrdInfo`**, and a `k8s_crd_toolchain` whose default builds
  controller-tools from the pin in `//:go.mod`.
- **`group`** is verified against the generated output rather than trusted, so
  the API group string (today retyped in many places per operator) has one home
  that cannot rot.
- **`post_processors`** — a dir-in/dir-out hook, for a schema that must be
  spliced over controller-gen's `x-kubernetes-preserve-unknown-fields` output
  (a runtime.RawExtension can only be rendered opaque).

Scaffolded but not built: `//k8s` (object/bundle/validate/diff), `//oci`
(`k8s_operator_image`), `//validate`, `//kubectl`.
